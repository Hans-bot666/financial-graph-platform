# 需求文档

## 1. 应用概述

### 1.1 应用名称
图谱应用平台

### 1.2 应用描述
基于 Nebula Graph 图数据库构建的行业图谱应用平台,支持模型构建、数据接入、探索分析、特征工厂和工作流管理等核心功能,为不同行业提供图谱数据管理与分析能力。

## 2. 用户与使用场景

### 2.1 目标用户
需要进行图谱数据管理、分析和可视化的业务人员、数据分析师和开发人员。

### 2.2 核心使用场景
- 构建和管理图谱模型
- 接入和处理图数据
- 探索和分析图谱关系
- 创建和管理场景看板
- 执行图谱查询和可视化分析

## 3. 页面结构与功能说明

### 3.1 页面结构

```
图谱应用平台
├── 1. 首页看板
├── 2. 模型构建
├── 3. 数据接入
├── 4. 探索分析
├── 5. 特征工厂
└── 6. Work Flow
```

### 3.2 功能说明

#### 3.2.1 顶部导航
- 展示 6 个页签:首页看板、模型构建、数据接入、探索分析、特征工厂、Work Flow
- 页签从左到右依次排列
- 点击页签切换至对应页面

#### 3.2.2 首页看板

**3.2.2.1 实体、关系统计**
- 位置:页面左上角
- 功能:统计并展示当前平台内所有实体数量和边关系数量
- 刷新方式:定期刷新

**3.2.2.2 场景看板**
- 布局:纵向排布
- 功能:
  - 支持自定义添加场景看板
  - 每个场景看板可自定义主题和名称
  - 场景看板内可包含多个子图看板
  - 子图看板来源:
    - 用户自定义添加
    - 从探索分析页面保存的子图
- 新建场景看板:
  - 创建后显示空白纵向区域
  - 区域内显示加号按钮
  - 点击加号跳转至探索分析页面的画布
- 子图看板管理:
  - 支持编辑子图看板
  - 支持删除子图看板

#### 3.2.3 模型构建

**3.2.3.1 图谱 Schema 可视化设计器**
- 提供可视化画布用于设计图谱模型
- 参考用户提供的图片 image.png 中的建模可视化方式
- 支持拖拽方式创建实体类型和边类型
- 支持可视化展示实体与边的关系结构

**3.2.3.2 实体类型(Tag)管理**
- 支持创建新的实体类型
- 支持编辑已有实体类型
- 支持删除实体类型
- 每个实体类型可配置:
  - 类型名称
  - 类型描述
  - 属性列表

**3.2.3.3 边类型(Edge Type)管理**
- 支持创建新的边类型
- 支持编辑已有边类型
- 支持删除边类型
- 每个边类型可配置:
  - 类型名称
  - 类型描述
  - 起始实体类型
  - 目标实体类型
  - 属性列表

**3.2.3.4 属性定义与约束配置**
- 为实体类型和边类型添加属性
- 每个属性可配置:
  - 属性名称
  - 数据类型(字符串、整数、浮点数、布尔值、日期等)
  - 是否必填
  - 默认值
  - 约束条件(唯一性、取值范围等)

**3.2.3.5 Schema 版本管理与迁移**
- 记录 Schema 的历史版本
- 支持查看不同版本的 Schema 定义
- 支持版本回退
- 支持版本对比

**3.2.3.6 模型导入/导出**
- 支持导出当前 Schema 模型为文件
- 支持从文件导入 Schema 模型
- 导入时校验模型格式和完整性

#### 3.2.4 探索分析

**3.2.4.1 画布功能**
- 提供图谱可视化画布
- 画布样式参考:https://g6.antv.antgroup.com/api/canvas
- 支持图谱节点和关系的可视化展示

**3.2.4.2 查询功能**
- 支持 GQL 查询语言输入
- 提供可视化查询构建器
- 查询结果在画布中展示

**3.2.4.3 子图保存**
- 支持将画布分析结果保存为子图看板
- 保存后的子图可显示在首页看板的场景看板中

## 4. 业务规则与逻辑

### 4.1 数据统计规则
- 实体和关系统计数据定期刷新,确保数据准确性
- 统计范围覆盖 Nebula Graph 数据库中的所有实体和边关系

### 4.2 场景看板规则
- 场景看板按创建顺序纵向排列
- 每个场景看板可包含多个子图看板
- 子图看板与探索分析页面的保存操作关联

### 4.3 探索分析规则
- 从首页看板场景看板的加号按钮跳转至探索分析页面
- 在探索分析页面保存的子图自动关联至对应的场景看板
- 支持 GQL 查询语言和可视化查询构建器两种查询方式

### 4.4 模型构建规则
- 实体类型和边类型名称在同一 Schema 版本中必须唯一
- 边类型必须指定起始实体类型和目标实体类型
- 删除实体类型或边类型前需检查是否被使用,若已有数据则提示用户
- Schema 修改后自动生成新版本
- 模型导入时若存在同名类型则提示用户选择覆盖或跳过

## 5. 异常与边界情况

| 场景 | 处理方式 |
|------|----------|
| 数据库连接失败 | 提示用户数据库连接异常,统计数据显示为 0 |
| 场景看板为空 | 显示提示信息引导用户添加子图看板 |
| 查询语法错误 | 提示用户查询语句错误,并给出错误信息 |
| 子图保存失败 | 提示用户保存失败,允许重新保存 |
| 删除场景看板 | 二次确认后执行删除操作 |
| 实体类型或边类型名称重复 | 提示用户名称已存在,要求修改 |
| 删除已有数据的类型 | 提示用户该类型已被使用,无法删除 |
| 模型导入格式错误 | 提示用户文件格式不正确,导入失败 |
| Schema 版本回退 | 二次确认后执行回退操作 |
| 属性约束冲突 | 提示用户约束配置冲突,要求修改 |

## 6. 验收标准

1. 顶部导航页签功能正常,点击可切换至对应页面
2. 首页看板左上角正确显示实体和关系统计数量
3. 场景看板支持自定义添加,可设置主题和名称
4. 场景看板内的加号按钮可跳转至探索分析页面
5. 模型构建页面提供可视化设计器,参考用户提供的图片 image.png 实现
6. 模型构建页面支持创建、编辑、删除实体类型
7. 模型构建页面支持创建、编辑、删除边类型
8. 实体类型和边类型可配置属性及约束条件
9. Schema 版本管理功能正常,支持版本查看、对比和回退
10. 模型导入/导出功能正常,支持文件格式校验
11. 探索分析页面画布功能正常,参考链接样式实现
12. 探索分析页面支持 GQL 查询语言输入和执行
13. 探索分析页面提供可视化查询构建器
14. 探索分析页面保存的子图可正确显示在首页看板的场景看板中
15. 子图看板支持编辑和删除操作
16. 实体和关系统计数据定期刷新
