# 按 Schema 生成 anti_fraud_kg

用 `backend/generate_graph.py`，按 `backend/schema.ngql` 向 NebulaGraph 5.x 写入 **anti_fraud_kg**。默认 **点 + 边合计 1,000,000**。

探索分析页不会自动画出整张图。必须用下面的 **ID 或名称** 做点查询，才能搜到数据。

## 规模

| 类型 | 数量 | 说明 |
| --- | ---: | --- |
| 合计 | 1,000,000 | 点 25 万 + 边 75 万 |
| 企业 company | 75,000 | ID `c_0000000` … `c_0074999` |
| 个人 person | 50,000 | ID `p_0000000` … `p_0049999` |
| 账户 account | 100,000 | ID `a_0000000` … `a_0099999` |
| 贷款 loan | 25,000 | ID `l_0000000` … `l_0024999` |
| 关系 | 750,000 | 9 种边近似均分，约各 83,333 条 |

Graph：`anti_fraud_kg`  
Graph Type：`anti_fraud_kg_type`  
默认 seed：`20260914`

## 名称与 ID 格式（用来搜索）

所有点的主键 `id` 都是 **1 位类型字母 + 下划线 + 7 位序号**（从 0 起）。

| 类型 | ID 格式 | 名称格式 | 可直接搜的例子 |
| --- | --- | --- | --- |
| 企业 | `c_0000000` | 前 3 个是固定中文名，其余为 `测试企业{7位序号}有限公司` | ID `c_0000000`；名称 `凯达建材有限公司` |
| 个人 | `p_0000000` | `测试人员{7位序号}` | ID `p_0000000`；名称 `测试人员0000000` |
| 账户 | `a_0000000` | `测试账户{7位序号}` | ID `a_0000000`；名称 `测试账户0000000` |
| 贷款 | `l_0000000` | `流动资金贷款{7位序号}` | ID `l_0000000`；名称 `流动资金贷款0000000` |

固定企业名（场景分析默认值，务必用全称）：

| 序号 | ID | 名称 | 说明 |
| ---: | --- | --- | --- |
| 0 | `c_0000000` | 凯达建材有限公司 | 贷款回流场景 |
| 1 | `c_0000001` | 东方贸易集团 | 担保圈场景 |
| 2 | `c_0000002` | 远景电子科技有限公司 | 失联客户场景（`is_lost=true`） |

后续企业名称示例：

- `测试企业0000003有限公司`（对应 `c_0000003`）
- `测试企业0074999有限公司`（最后一家企业）

序号必须 **补齐 7 位**。`测试人员0`、`c_0` 都搜不到。

## 在探索分析里怎么搜

1. 打开「探索分析」，当前分析图选 **对公贷款反欺诈图 · anti_fraud_kg**（图未写完或未启动后端时列表可能为空）。
2. 点查询：
   - **按实体 ID**：输入 `c_0000000`、`p_0000000`、`a_0000000`、`l_0000000`。
   - **按名称**：实体类型选 `company` / `person` / `account` / `loan`，再输入上表全称，例如 `测试账户0000123`。
3. 命中节点后，再用「关系展开」看邻居。

顶栏全局搜索只搜页面/功能，**不会**搜图数据库里的点。

## 关系类型

展开或路径查询时可选这些边（与 Schema 标签一致）：

`holds_account`、`applied_for`、`disbursed_to`、`transfer`、`guarantees`、`controls`、`shareholder`、`employs`、`related_to`

## 命令

在 `backend` 目录：

```powershell
# 只看规模和样例语句，不写库
python generate_graph.py --dry-run

# 写入 100 万（点+边）
python generate_graph.py --yes

# 图已存在时删掉重建
python generate_graph.py --recreate --yes
```

导入过程会先写完 25 万个点，再写 75 万条边，可能需要较长时间。进度按每 5 万条打印。同一种关系的 `(src, dst)` 不会重复（NebulaGraph 5.x 不允许同类型多重边）。中途失败后必须 `--recreate --yes` 重建，不能在半成品图上续写。
