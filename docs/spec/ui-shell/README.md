# 主工作台 UI Shell

## 1. 文档信息

- 状态：Draft
- 版本：0.4.0
- 更新时间：2026-09-14
- 适用范围：登录后主工作台壳层（`MainLayout` / `SideNav` / `TopNav`），不含登录/注册页

业务模块通过 `TabKey` 切换；用户管理是权限门控的第六个工作台 Tab，不再使用独立管理壳。

## 3. 为什么要做（Why）

### 3.1 现状

1. 顶部横向页签占用顶栏空间。
2. 圆盘菜单隐藏入口，展开形态与目标设计稿不一致。
3. 可折叠侧边栏兼顾入口可见性与内容宽度。
4. 顶栏展示当前图空间容易与探索页的实际选择混淆；用户管理位置不合理，用户角色不可见。
5. 场景和子图数量增加后缺少统一搜索与最近访问入口。

### 3.2 目标

1. 提供默认窄栏、悬停浮层展开的左侧模块导航。
2. 五个业务模块入口仍完整可达，**切换逻辑与现有 `activeTab` / `onTabChange` 一致**。
3. 管理员入口按权限迁入侧栏，并作为 `admin` Tab 渲染在同一 Layout 内；顶栏展示用户角色。
4. 视觉延续平台主色（蓝）与图谱节点意象 Logo，与截图气质一致，但不引入无关装饰噪音。
5. 顶栏中部支持搜索场景和子图，并展示最近搜索历史。

### 3.3 非目标

- 不改各页面内部业务逻辑（看板 CRUD、建模、接入、探索、特征、用户 CRUD/RBAC API）。
- 不改 `RouteGuard`、登录/注册壳。
- 用户管理并入侧栏 Tab，退出仍保留在顶栏用户区。
- 不做完全复刻截图中的虚假统计条/假数据；内容区以现有 `HomePage` 等为准，仅壳层导航变更。

### 3.4 原则

| 原则 | 说明 |
| --- | --- |
| 逻辑不变 | 业务模块仍是 `TabKey` 切换；用户管理为权限门控的第六态 |
| 悬停展开 | 默认窄栏，鼠标进入展开、离开收回 |
| 可达性 | 键盘与屏幕阅读器仍能打开并选择 |
| 不挡操作 | 侧栏参与主布局，不覆盖内容 |

## 4. 成功标准（摘要）

1. 默认仅显示 Logo 与模块图标。
2. 鼠标进入显示平台名称与菜单文字，离开自动收回。
3. 顶栏不再用横向页签作为主模块导航。
4. 点击菜单项可正常切换页面，当前项有选中态。

详见 [sidebar-nav.spec.md](sidebar-nav.spec.md)。
