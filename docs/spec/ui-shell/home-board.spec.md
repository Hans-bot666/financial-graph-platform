# 场景看板首页 UI

- 规格 ID：UI-HOME
- 状态：Draft → Implementing
- 依据：用户提供的场景看板设计稿

## Why

现首页左侧统计栏 + 右侧看板列，与目标设计稿不一致；设计稿中的「近期分析报告」不需要。

## How（本期）

1. **全宽主区**：去掉左侧常驻统计栏；无分析报告列表。
2. **页头**：标题「场景看板」+ 场景数量徽章 + 说明文案 +「+ 新建场景」。
3. **统计条**：浅蓝横幅展示已保存实体/关系数与「图谱持续更新中」状态（数据仍来自 `localGraphStats`）。
4. **我的分析场景**：等宽网格，大屏一行 **4** 列占满横向；超出自动换行，**禁止横向滚动条**。
5. **逻辑不变**：创建/编辑/删除看板与子图、跳转探索分析的回调保持原样。

## 非目标

- 不恢复「近期分析报告」。
- 不改 board-store 数据模型。
