# 可折叠左侧主导航规格

## 1. 信息

- 规格 ID：UI-SIDEBAR
- 状态：Implemented
- 更新时间：2026-09-14
- 依赖：现有 `MainLayout` + `TabKey`（含权限门控的 `admin`）

## 2. Why

圆盘菜单的环形布局不符合当前场景看板设计稿。主导航改回设计稿中的左侧栏，并通过悬停展开兼顾入口可见性与内容区宽度。

## 3. How

1. 左侧栏默认收缩为窄栏，仅显示 Logo 和菜单图标。
2. 鼠标进入侧栏后自动展开，展示平台名称和菜单文字。
3. 鼠标离开侧栏后自动收回窄栏，无需点击。
4. 窄栏图标提供 `title` / `aria-label`，当前模块保留蓝色选中态。
5. 页面布局始终只预留窄栏宽度；展开面板绝对定位并浮在主界面上方，不挤压或改变主内容宽度。
6. 展开态增加向右侧扩散的柔和阴影，用边界与主内容建立层级，不使用厚重黑边。
7. 五个业务模块仍通过 `TabKey` / `onTabChange` 切换；用户管理使用同一机制（`admin`），不另开路由壳。

## 4. 导航项

- 场景看板
- 模型构建
- 数据接入
- 探索分析
- 特征工厂
- 用户管理（仅 `user.read`；点击 `onTabChange('admin')`，选中态与上列一致）

## 5. 验收

- 首次进入默认显示窄栏。
- 鼠标放入自动展开，离开自动收回。
- 窄栏状态下所有模块仍可点击。
- 展开时右侧主界面的位置与宽度不发生变化。
- 选中态与当前页面一致。
- 圆盘菜单不再渲染。
